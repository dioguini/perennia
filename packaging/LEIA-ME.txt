PERENNIA — COMO USAR
=====================

Não precisas de instalar nada: o Python e as bibliotecas vêm cá dentro.


1. ABRIR
--------

Windows: abre Perennia.exe.

  Da primeira vez o Windows pode mostrar "O Windows protegeu o PC". É porque
  a aplicação não está assinada digitalmente (isso custa dinheiro todos os
  anos). Carrega em "Mais informações" e depois "Executar mesmo assim".
  Só acontece uma vez.

macOS: botão direito em Perennia.app → Abrir → Abrir. (Duplo clique da
  primeira vez não deixa, por a app não estar assinada.) Da primeira vez
  que procurares sensores, o macOS pede autorização para o Bluetooth: aceita.

Linux / Raspberry Pi: descompacta e corre ./Perennia/Perennia


2. PRIMEIROS PASSOS
-------------------

  Definições   → o teu nome, peso e FTP
  Dispositivos → Procurar (Bluetooth) ou Procurar ANT+ (antena USB)
                 Sem hardware, escolhe "SEM HARDWARE - Trainer" para experimentar.
  Pedalar      → Importar .gpx: põe os teus .gpx em data/in/gpx (ao lado da
                 aplicação) e escolhe-os na lista.

Durante a sessão (as mesmas teclas em todos os desportos):
  L = volta · P = pausa (aparece o aviso PAUSA ao centro) · N = saltar bloco ·
  Espaço = começar sem esperar pela contagem · F10 ou "■ Terminar" = acabar e
  gravar · F4 = Dispositivos e F8 = Definições (a sessão fica em pausa) ·
  F11 = ecrã inteiro.
  Todas as teclas podem ser mudadas em Definições → Atalhos de teclado.


3. ONDE FICAM OS DADOS
----------------------

Tudo numa só pasta, "data", AO LADO da aplicação (criada na primeira vez que
a abres):

  data/perennia.db      a base de dados (o estado da aplicação)
  data/in/...           o que queres IMPORTAR: põe aqui os ficheiros
                        (gpx, treinos, planos, csv, atividades, analises,
                        hrv4training, trainingpeaks, historico, backups)
  data/out/...          o que a Perennia GRAVA: sessoes/<desporto> (o .fit de
                        cada sessão, pronto para o Strava, Garmin Connect ou
                        Intervals.icu), treinos, planos, csv, powerbi,
                        backups, relatorios
  data/garmin/...       o GarminDB (configuração sem palavra-passe e os dados
                        que descarrega)

As listas de importação só mostram o que está na pasta data/in certa.
Arrastar um ficheiro para a janela funciona com um ficheiro de qualquer sítio.

Quem já usava uma versão anterior (dados em %APPDATA%\Perennia,
~/Library/Application Support/Perennia ou ~/.local/share/perennia) não tem de
fazer nada: na primeira vez, tudo é COPIADO para "data" (os originais ficam
onde estavam; apaga-os quando confirmares que está tudo).

PARA ATUALIZAR A APLICAÇÃO: os dados estão dentro desta pasta. Copia a pasta
"data" da versão antiga para a pasta da versão nova (ou faz um backup antes e
repõe-no na nova).


4. ANTENA ANT+ NO WINDOWS (só se usares ANT+)
---------------------------------------------

O Bluetooth funciona sem mais nada. Para a antena ANT+ é preciso trocar o
driver uma vez, com o programa gratuito Zadig (https://zadig.akeo.ie):

  1. Liga a antena e fecha o Zwift / Garmin Express.
  2. No Zadig: Options → List All Devices.
  3. Escolhe a antena (ANT USB-m Stick, ANT USBStick2…; o ID começa por 0FCF).
  4. Escolhe WinUSB e carrega em "Replace Driver".

Outras aplicações que usem o driver da Garmin podem deixar de ver a antena.
Para voltar atrás: Gestor de Dispositivos → a antena → Reverter driver.


5. SE ALGO CORRER MAL
---------------------

Se a aplicação fechar com um erro, aparece uma janela a dizer onde ficou o
ficheiro perennia-erro.log (na pasta dos dados). Envia esse ficheiro a quem
te passou a aplicação.
